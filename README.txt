MOTO GARAGE V2 — BASE DE PRUEBAS

1. Descomprime el ZIP.
2. Sube index.html, style.css, app.js y la carpeta assets a tu repositorio de GitHub.
3. Activa GitHub Pages desde Settings > Pages.
4. Selecciona Deploy from a branch, rama main y carpeta / (root).
5. Abre la URL de GitHub Pages.

Esta primera versión es deliberadamente sencilla: pantalla principal basada en el diseño aprobado, menú funcional, pantallas básicas y datos iniciales de la SV650S.
